# Frontend de Personal Planner

Aplicación React y TypeScript para las vistas Hoy, Hábitos y Finanzas. Usa Vite, TanStack Query,
React Router y primitivas accesibles de Radix UI.

```bash
npm install
npm run dev
```

La API se consulta en `http://localhost:8000/api`. Define `VITE_API_BASE_URL` para cambiarla.

```bash
npm run lint
npm test
npm run build
```
